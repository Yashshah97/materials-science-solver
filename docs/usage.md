# Usage

```python
import materials_science_solver
```

Each module is self-contained; see docstrings for the API:

- `materials_science_solver.materials` — Module containing data structures and constants for materials science
- `materials_science_solver.solver` — Heuristic constraint solver with pluggable strategies
- `materials_science_solver.strategies` — Module containing various solving strategies that can be plugged into the solver
- `materials_science_solver.benchmarks` — Module containing functions to run benchmarks on the solver's performance
- `materials_science_solver.utils` — Miscellaneous utility functions for the project, such as logging and parsing
- `materials_science_solver.tests` — Unit tests for the module using Python's built-in unittest framework
